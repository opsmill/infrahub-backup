`infrahub-taskmanager flush flow-runs` works with Infrahub 1.13 and later, where `infrahub tasks flush flow-runs` takes no number of days. With those releases it deletes the runs older than the task history retention set on the task manager (`INFRAHUB_TASK_MANAGER_RETENTION_TASK_HISTORY`), warns when `days_to_keep` or `batch_size` is given because they are ignored, and with the new `--rewrite` flag rewrites the tables that are mostly free space to return their disk space. With earlier releases the command behaves as before.
