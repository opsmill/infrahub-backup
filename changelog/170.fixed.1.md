The Kubernetes backup permissions table now lists `get` and `patch` on the `deployments/scale` and `statefulsets/scale` subresources to match the Role the Helm chart creates, and the page says that the backup uses only `patch` on them. It listed `patch` on `deployments` and `statefulsets`, which does not allow `kubectl scale`, so a Role built from it made Infrahub Community backups fail at the first scale-down.
