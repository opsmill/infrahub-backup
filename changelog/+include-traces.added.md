Added `--include-traces` to `infrahub-collect create`. It adds the traces of slow requests from Tempo to the support bundle, slowest first, with personal data removed, within a size limit, and records the trace sampling ratio when an Infrahub API token is given. On Docker Compose the collector reads the published port 3200 of the `infrahub-tempo` service; on Kubernetes it forwards a port to the service labelled `app.kubernetes.io/name=tempo`, which needs `list` and `get` on `services`, `get` and `list` on `pods`, and `create` on `pods/portforward`; none of these is needed with `--traces-tempo-url`. Both are new assumptions about the deployment. The `bundle_information.json` version changed to `2026110500`: collector entries can now have a `details` object.
